1. 用户登录 - 获取 JWT Token

2. 测试需要认证的接口

3. 使用说明

在 Swagger UI 中使用认证：

  1. 点击上方"登录"按钮获取JWT Token
  2. 复制返回的token值（不包括"Bearer "前缀）
  3. 在Swagger UI页面点击右上角的🔒"Authorize"按钮
  4. 在弹出的对话框中，在"bearer (http, Bearer)"字段中粘贴token
  5. 点击"Authorize"，然后点击"Close"
  6. 现在所有需要认证的接口都可以正常使用了
